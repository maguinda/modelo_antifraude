    3Lo que ya sabemos de esta compra
    
        
    Se detecta solo: la conexión la ve el servidor, el dispositivo lo detecta el navegador y la verificación del cliente sale de los registros de la tienda. No tienes que llenar nada.
    
        
    
        
        
    
          
    Aquí decides lo que normalmente se detecta solo, para ver cómo reacciona el antifraude ante una VPN, una cuenta nueva, etc.
    
          
    
            
    
          
    
            
    
          
    La tienda manda solo la IP; la API la ubica con su proveedor de IP (aquí simulado, solo reconoce estos rangos de prueba).
